Select All Button

Add a clear button above supported line tabs.

Row Toggle Icon

Select or unselect each row with a compact icon.

Hidden Boolean State

Reusable JS Widget

Usage

Install and Use Immediately

Open a supported document form, go to its line tab, and click Select All.

1. Install

Install the module from Apps or update it from command line.

2. Open Lines

Open Sales, Purchase, Invoice, MO, or Transfer document lines.

3. Select

Click Select All, then toggle specific rows when needed.

Custom Widget Usage

<field name="your_boolean_field" widget="sm_select_all_boolean"/>
